# Facilities page update

- `/facilities` is a single page with five anchored sections.
- Home page facility cards link to `/facilities#library`, `#science-laboratories`, `#computer-laboratory`, `#playground`, `#smart-classrooms`.
- Header and mobile navigation include Our Facilities.
- English/Marathi text is switched with the existing language context.
- Images are illustrative and should be replaced with approved school photos before publication.
- Specific equipment and facilities must be verified by the school; descriptions intentionally avoid unverified claims.

If applying to an existing project, copy `src/components/FacilitiesPage.tsx`, `src/components/facilities.css`, and `src/app/facilities/page.tsx`, then apply the home card and header changes shown in `src/components/Pages.tsx` and `src/components/SiteChrome.tsx`.
